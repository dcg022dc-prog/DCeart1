## 📱 Android

El objetivo es que DCeart pueda utilizarse también desde Android
mediante una interfaz web adaptable o una aplicación Android
independiente.

La disponibilidad de cada función dependerá de las APIs y fuentes de
datos utilizadas.

------------------------------------------------------------------------

## 📚 Fuentes y licencias

DCeart puede utilizar software, mapas, bibliotecas y APIs de terceros.

Cada componente debe conservar su licencia y sus atribuciones
correspondientes.

**Importante:** que DCeart sea de código abierto no significa que todos
los datos externos utilizados por la aplicación sean libres de cualquier
restricción. Antes de incorporar una fuente, debe revisarse su licencia,
términos de uso y requisitos de atribución.

## 🤝 Contribuciones

Las contribuciones son bienvenidas.

Si quieres colaborar:

1.  Crea un fork del proyecto.
2.  Crea una rama para tu modificación.
3.  Realiza tus cambios.
4.  Prueba el funcionamiento.
5.  Abre un Pull Request explicando claramente la modificación.

Las contribuciones deben respetar la licencia del proyecto y las
licencias de terceros.

------------------------------------------------------------------------

## ⚠️ Uso responsable

DCeart está pensado para **visualización, investigación, aprendizaje y
uso legítimo de información pública**.

No debe utilizarse para:

-   vigilancia ilegal;
-   seguimiento de personas sin autorización;
-   acceso no autorizado a sistemas;
-   recopilación de información privada;
-   actividades que infrinjan las leyes aplicables.

------------------------------------------------------------------------

## 📄 Licencia

Si el código base utilizado por la distribución de DCeart se encuentra
bajo una licencia permisiva como **MIT**, el proyecto debe conservar los
avisos de copyright y las condiciones exigidas por dicha licencia.

**No elimines las atribuciones de los autores originales ni las
licencias de componentes de terceros.**
